# kinoMotion Light Mode — Dohna Dohna 主题设计规范

> 主视觉参考：《多娜多娜 一起来干坏事吧》（ドーナドーナ / Alicesoft, 2020）
> 暗色主题参考：《女神异闻录 5 皇家版》（见各组件 `:global(.theme-dark)` 规则）

---

## 1. 参考作品视觉分析

《多娜多娜》的 UI 是「波普赛博（Pop Cyber）」风格，与 P5R 的「先锋海报」风格的关键差异：

| 维度 | 多娜多娜 | P5R |
| --- | --- | --- |
| 底色 | 暖白 / 浅色为主 | 纯黑 |
| 配色 | 高饱和品红 + 青 + 黄三色撞色 | 黑 / 白 / 红单点强调 |
| 形状 | 粗墨线描边的平面色块、圆角与斜切混用 | 锐利斜切、无描边色块 |
| 装饰 | 半调网点、斜纹警示带、星形/十字闪光 | 大字叠影、幽灵描边字 |
| 气质 | 喧闹、游戏厅般的霓虹波普 | 冷峻、怪盗团的叛逆海报 |

因此 Light Mode 不是 Dark Mode 的反色，而是换了一个视觉世界：**暖纸底 + 品红/青/黄撞色 + 墨线描边**。

## 2. 设计令牌（Design Tokens）

全部定义于 `src/styles/global.css` 的 `:root`（亮色域）。组件只引用令牌，不写死色值。

### 2.1 核心色板

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--dd-pink` | `#ff1f6d` | 主强调色：链接、hover 填充、选中态、硬阴影、描边字 |
| `--dd-pink-deep` | `#d1004f` | 主色按压/深态 |
| `--dd-cyan` | `#00cfe3` | 第二强调色：日期 chip、标签、TOC hover、箭头按钮 |
| `--dd-yellow` | `#ffc900` | 第三强调色：跑马灯带、行内 code、星形装饰、页脚锯齿 |
| `--dd-ink` | `#1b1426` | 墨色：正文、描边、边框（带紫调的黑） |
| `--dd-paper` | `#fff9f0` | 页面底色（暖白） |
| `--dd-pastel-pink` | `#ffe1ec` | 浅粉表面层（surface-variant） |
| `--dd-pastel-cyan` | `#ddf7fb` | 浅青表面层（WavyLines 场） |
| `--dd-pastel-yellow` | `#fff3c4` | 浅黄备用层 |

### 2.2 槽位映射（双主题共享组件代码的关键）

`--p5-red` / `--p5-ink` / `--p5-paper` 是**按主题域化的槽位**：

| 槽位 | Light (Dohna Dohna) | Dark (P5R) |
| --- | --- | --- |
| `--p5-red` | `#ff1f6d` 品红 | `#e60012` 怪盗红 |
| `--p5-ink` | `#1b1426` 紫调墨 | `#17130f` 暖调墨 |
| `--p5-paper` | `#fff9f0` 暖白 | `#f5f1e8` 米色 |

组件中所有 `var(--p5-red)` 在切换主题时自动换色；亮色独有的青/黄装饰通过 `--dd-*` 令牌在亮色系规则中显式引用（亮色系规则 = 不带 `.theme-dark` 前缀的基础规则）。

### 2.3 共享几何/动效令牌（两主题完全一致）

- `--cut-notch`：切角多边形（卡片、pre、aside）
- `--skew-ui: -8deg`：UI 斜切基准角（实际组件用 -4° ~ -12°）
- `--hard-shadow*`：0.32em 无模糊硬阴影
- 动效时长：hover 0.18s ease、菜单下划线 0.25s cubic-bezier(0.22,1,0.36,1)、转场 560ms/800ms
- 字体：`--font-family-display`（Impact + MiSans）、`--font-family-sans`（MiSans）、`--font-family-sans-code`（Roboto Mono）

## 3. 核心组件视觉规范（Light Mode）

### 3.1 排版与正文

- 标题：墨色填充 + 品红错位叠影 + 纸色第三层叠影（`0.05em pink / 0.09em paper`）
- 描边字（幽灵序号、SIGNAL）：透明填充 + 品红 0.03~0.035em 描边
- 正文链接：品红下划线，hover 品红填充反白
- 行内 `code`：**黄底墨字 + 墨边框 + 品红小硬影**（DD 标志性黄 chip）
- `pre` 代码块：Shiki `#1e1e1e` 底 + 墨边框 + 品红硬影 + 切角（与暗色一致的结构，阴影换色）
- `blockquote`：白底 + 3px 墨边框 + 品红侧向硬影（暗色为无框白块）
- 表格表头：品红底白字 + 墨底线
- `hr`：品红/青/黄三色斜纹带（暗色为白/红/黑）

### 3.2 导航（Header / HeaderLink）

- 页签：透明底 + 墨边框 + 斜切 -8°
- hover：**青底墨字 + 品红硬影**（撞色反馈）
- 选中：**品红底白字 + 墨硬影** + 白色下划线
- 主题切换按钮：**黄底墨图标** + 品红硬影；hover 品红反白
- 滚动收起：纸底 + 品红 4px 底边 + 右下斜切（结构同暗色）

### 3.3 Hero（Welcome）

- 背景：品红/青双色 112° 斜纹 + 暖白罩层 + 品红半调网点（右上径向遮罩）
- 主标题 KINO：墨字 + 品红/纸双层叠影；MOTION：品红字 + 墨/纸叠影（与暗色的白字/描边字处理形成镜像）
- 红色斜切横幅 → 品红（同槽位自动换色）
- 星形装饰：大黄星（金）+ 小**青星**
- kicker chip：品红底白字；hero-sub：墨底纸字 + 品红边框与菱形 bullet
- 底部跑马灯：**黄底墨字 + 品红描边字 + 品红边框**（`marquee-red` 的亮色变体）

### 3.4 卡片与列表（BlogLink / PostGrid）

- 卡片：白底 + 3px 墨框 + 切角 + 品红硬影，偶数卡 ±0.8° 倾斜
- 幽灵序号：透明 + 品红 2.5px 描边
- 日期 chip：**青底墨字**（暗色为白底黑字）
- hover：品红填充、白字、墨硬影、回正（两主题一致）
- 条目计数 chip：青底墨字 + 墨框 + 品红影

### 3.5 文章页（BlogPost）

- 日期 chip：品红底白字 + 墨影
- 标签：**青底墨字 + 墨框 + 品红影**
- TOC：hover 青底墨字斜切；active 品红底白字 + 墨左线（暗色为白底选择带）

### 3.6 首页区段

- About：白卡 + 墨框 + 品红硬影；幽灵 01 品红描边（32% 透明）；状态 chip 白底墨框品红影；头像框黄星
- Poker：白卡墨框 + **品红硬影**；箭头按钮黄底墨框；POKER 标题墨描边 + 品红影
- WavyLines：**浅青场 + 品红波纹线** + 黄色菱形指针点 + SIGNAL 品红描边字（暗色为红场黑波）

### 3.7 全局控件

- Loader 转场三层面板：**品红（前）/ 黄（中）/ 青（后）**，亮色 front 叠加白色细纹（暗色为红/墨/纸）
- Footer：**品红底白字** + 黄色锯齿上沿 + 白/青斜纹带；链接按钮白框黄影（暗色为黑底红锯齿）
- BackToTop：品红底白图标 + 墨框；hover 青底墨图标
- ScrollBar：滑块激活态品红 + 暗色白边（结构一致）
- Cursor：difference 混合菱形环，两主题通用

## 4. 双主题关系

### 不同的视觉个性

| | Light — Dohna Dohna | Dark — P5R |
| --- | --- | --- |
| 世界观 | 白昼游戏厅，喧闹波普 | 午夜怪盗团，冷峻海报 |
| 色彩逻辑 | 三原色撞色（品红/青/黄） | 单点强调（红）+ 黑白对比 |
| 表面 | 暖纸 + 白卡分层 | 纯黑 + 白/红色块 |
| 描边 | 粗墨线（存在感强） | 白线/无线 |
| 装饰纹理 | 彩色斜纹、半调网点 | 单色斜纹、幽灵大字 |

### 共享的体验一致性

- **信息架构**：页面结构、组件层级、栅格完全一致（同一套 Astro/Svelte 组件，无双份模板）
- **几何语言**：斜切角、切角多边形、硬阴影、倾斜排布完全共享令牌
- **交互体验**：hover 时长与缓动、磁吸/倾斜/视差参数、Loader 转场编排骨架、ScrollTrigger 触发点全部一致——仅颜色与纹理表现层差异化
- **可读性**：两主题正文对比度均 ≥ WCAG AA（亮 #1b1426 on #fff9f0 ≈ 14:1；暗 #fff on #0c0c0c ≈ 18:1）
